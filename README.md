# Insurance Policy Management System

MSCS-532: Algorithms and Data Structures

## Project Overview

This project explores the use of Python data structures
to manage fictional insurance policy records efficiently.

## Selected Data Structures

- Dictionary for policy storage and lookup
- Heap-based priority queue for policy review scheduling

## Project Phases

Phase 1: Data structure design and foundational implementation
Phase 2: Proof-of-concept implementation and testing
Phase 3: Optimization and performance evaluation
Phase 4: Final report and presentation
